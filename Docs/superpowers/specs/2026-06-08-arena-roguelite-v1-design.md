## 1. 定位与原则

- **一句话**：操控一个近战骑士，在一个竞技场里抵挡一波波涌来的敌人，每波之间三选一强化自己，撑过 N 波则胜利，倒下则本局结束、重开。
- **核心设计原则（防弃坑）**：
  1. **范围极小、必须能做完**——v1 砍到最小完整循环。
  2. **尽早出现可见胜利**——第一个里程碑就是「骑士在竞技场砍怪」跑在屏幕上，喂动力。
  3. **最大化复用**现有 Valoris 已写好的系统（GAS 战斗、波次、角色、动画、HUD）。
  4. **合作模式 B**：用户为架构师/审查者并做设计决策；AI 写实现并讲清概念/原理；用户理解系统、可改可审。

---

## 2. 核心循环

```
进入竞技场
  → 一波敌人从四周涌向玩家
  → 玩家用近战攻击 + 闪避清怪
  → 清完该波
  → 【三选一】随机强化
  → 下一波（更多、更强）
  → 撑过第 N 波 = 胜利结算
  → 玩家血量归零 = 失败结算
  → 重开新局（永久死亡，不存档不解锁）
```

## 3. 操控与镜头（顶下 WASD 直控）

| 输入 | 功能 |
|------|------|
| WASD | 移动（直接控制，非点击寻路） |
| 鼠标 | 决定角色朝向 |
| 左键 | 近战挥砍（朝当前朝向，复用 `GA_MeleeAttack`） |
| 空格 | 闪避翻滚（带无敌帧，复用 `GA_Charge` 改造 + 现有 Dodge/Roll 动画） |
| Q / E | 1~2 个主动技能（复用 `GA_MeleeAOE` 旋风斩 / `GA_Buff` 临时增益） |
| ESC | 暂停 |

- **镜头**：略带俯角的跟随相机（角色身上 SpringArm + Camera，俯视角约 45–60°，固定距离）。一屏能看清四周涌来的敌人。
- 替换掉原 RTS 风格 `ValorisSpectatorPawn`（边缘平移/缩放/旋转）与点击移动逻辑。

---

## 4. 战斗（复用现有 GAS，少量改造）

**直接复用（保留）**：`ValorisAttributeSet`、`ValorisGameplayTags`、`GA_MontageAbilityBase`、`GA_MeleeAttack`、`GA_MeleeAOE`、`GA_Charge`、`GA_Buff`、`GE_Damage`、`GE_Cooldown`、`GE_Buff`、`ExecCalc_Damage`、`AnimNotify_SendGameplayEvent`。

**改造**：
- 攻击从「自动锁定目标」改为「玩家手动挥砍 + 朝向判定」（近战命中检测：角色前方扇形/胶囊范围）。
- `GA_Charge` 改造为「闪避翻滚」：短距位移 + 期间施加 `State.Invincible` 无敌标签 + 翻滚动画。

**新增**：
- **敌人主动攻击玩家**：敌人需要近战攻击能力（复用 GAS 机制），命中对玩家 ASC 施加 `GE_Damage`。
- 玩家受击/死亡处理（受击动画 + 血量归零触发失败）。

## 5. 玩家角色

- **英雄 Aric**（Dark Crusader Knight 写实骑士 + 剑盾），动画已重定向完成（Idle/Walk/Run/Attack/Dodge/Roll/Hit 已整理）。直接复用。
- v1 只做这 1 个英雄。

---

## 6. 敌人

- **2~3 种**（v1）：
  - 普通：标准血量/速度，近战。
  - 快速：低血、高速，近战。
  - 坦克：高血、低速，近战（数量少）。
- 行为：从竞技场边缘生成 → 追向玩家 → 进入攻击距离后攻击玩家。
- 复用 `EnemyBase` / `EnemyAnimInstance` / `HealthBarWidget`；**重写 `EnemyAIController`**（现为空壳）实现「追玩家 + 攻击」。
- 美术：用现有 Fab 中世纪角色 + 重定向战斗动画（注意：每种敌人需配攻击动画，是一块工作量）。

---

## 7. 波次系统

- 复用 `WaveData`（DataAsset）+ GameMode 波次逻辑，**改造生成方式**：
  - 原：沿 Spline 路径走向基地。
  - 新：在玩家四周的竞技场边缘环形/随机点生成，敌人直接奔向玩家。
- 每波配置：敌人类型与数量、生成节奏。波数递增、强度递增。
- v1：约 **8~10 波**，最后一波带一个**小 Boss**（用某个更强的角色 + 高数值）。

---

## 8. 升级系统（局内三选一）—— 新增

- 每清完一波，弹出 **3 个随机强化**，玩家选 1。
- 强化以 **GameplayEffect** 形式挂到玩家 ASC（复用 GAS 数值机制）。
- v1 强化池（约 8~10 种）：+攻击力、+攻速、+移速、+最大生命、吸血、AOE 范围扩大、闪避冷却缩短、攻击范围扩大、击杀回血、暴击几率……
- 数据驱动：强化定义用 DataAsset/表，便于后续加内容（呼应用户「重复内容系统化」的做法）。
- 新增一个**三选一 UI Widget**。

---

## 9. 流程与胜负

- 开始 → 进竞技场 → 波次循环（夹三选一）→ 撑过第 N 波=胜利 / 玩家死亡=失败 → 结算面板（用时/波数/击杀数）→ 重开。
- 复用并改造现有胜负判定：把「基地血量」改为「玩家血量」。
- HUD：玩家血条、当前波数、本波剩余敌人数、（可选）击杀数/计时。

---

## 10. 复用 vs 新写 vs 删除（看它多小）

**♻️ 复用（基本不动）**：GAS 全套（属性/标签/技能基类/伤害计算/效果）、`ValorisCharacterBase`+ASC、`AricHero`、`HeroAnimInstance`、`EnemyBase`/`EnemyAnimInstance`、`HealthBarWidget`、`ValorisHUD` 框架、`ValorisAssetManager`、Aric 剑盾动画集。

**🔧 改造**：`ValorisPlayerController`（输入改顶下 WASD + 手动攻击/闪避）、相机（RTS→跟随）、`GA_MeleeAttack`（自动→手动朝向）、`GA_Charge`（→闪避）、`EnemyAIController`（空壳→追+打）、波次生成（路径→环绕玩家）、胜负（基地血→玩家血）。

**🆕 新写**：顶下跟随相机、敌人攻击玩家的能力与受击、三选一升级系统+UI、强化数据池、竞技场地图布置。

**🗑️ 删除（保留 git 分支备份）**：`Tower/`、`Building/`、`GA_TowerAttack`、`BuildPreview`、塔防经济（`ResourceManager` 视情况删/留）、RTS 相机 `ValorisSpectatorPawn`、点击移动逻辑。

## 11. 范围边界（v1 明确取舍）

**v1 包含**：1 个固定竞技场地图、1 个英雄、2~3 种敌人、8~10 波+小Boss、局内三选一升级、永久死亡+重开、HUD、胜负结算、基础特效音效、打包上线 itch.io。

**v1 不做（放 v2）**：随机地图生成（proc-gen）、局外养成/永久解锁/存档、多英雄、多武器流派、联机、剧情/酒馆主城。

## 13. 风险与应对

| 风险 | 应对 |
|------|------|
| 敌人攻击动画重定向工作量 | v1 只做 2~3 种敌人；优先用已重定向好的动画/同骨架角色 |
| 控制/相机改造牵动 PlayerController | 先在 M1 把新控制跑通，确认手感再继续 |
| GAS 记忆生疏 | 模式 B：AI 讲概念+复用现有工作代码当教材 |
| 范围蔓延（弃坑主因） | 严守 v1 边界；新点子记入 v2 待办，不进 v1 |
| 隔代引擎/工具链问题 | 已验证 5.7.4 编译通过（41s）作为基线 |

## 14. 资产使用（来自用户 Fab 库）

- 英雄：Dark Crusader Knight（已在工程内，Aric）。
- 敌人：从现有中世纪角色中选 2~3 个（如其它骑士/亡灵类）+ 重定向战斗动画包（剑盾/单手剑等，用户已有大量）。
- 竞技场环境：从现有中世纪环境包选 1 个（如 Dungeon Catacomb / Medieval 场景）裁出一块封闭竞技场。
- 武器/盾：现有奇幻近战武器+盾资产。
